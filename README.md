HELLO HONEY — RECREATED WEBSITE STARTER
======================================

This is a much more detailed visual recreation of the publicly visible Hello Honey site:
- Home
- Our services
- How it works
- About us
- The nail edit (gallery)
- Book your moment

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Safari.
3. Internet is needed for the Google Fonts and Unsplash image URLs to load.

IMPORTANT LIMITATIONS
- This is a static front-end recreation, not the original site's source code.
- Photos are external visual placeholders and may not be the exact images used on the live site.
- The booking form is a demo only. It does not send or save customer details.
- Do not collect real customer information with this copy until a secure form/backend is connected and tested.
- No live website is changed by opening these files locally.

TO PUBLISH FOR FREE
You will need a free static hosting account that allows manual upload, or connect these files to a free hosting provider. Do not pay to upgrade just to preview this folder.
